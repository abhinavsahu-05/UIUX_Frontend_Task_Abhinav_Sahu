# DroneTV Website Clone

This is a responsive multi-page frontend website built for a drone service platform. It includes pages like Home, Services, Courses, Products, Login, and a User Dashboard.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository to your local machine.
2. Open the project folder in VS Code.
3. Run `index.html` using the **Live Server** extension in VS Code.
